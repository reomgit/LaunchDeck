# LaunchDeck Alpha 0.2

Changes since [Alpha 0.1](https://github.com/reomgit/LaunchDeck/releases/tag/Alpha), the previous release.

## New and improved

- Automatic app profiles follow the focused application, fall back to Global, and apply edits immediately. Temporary overrides are available under Advanced and end on resume or restart.
- Keyboard shortcuts are recorded in a dedicated capture sheet until Done or Cancel, including system combinations such as Command-Tab. Capture is cancelled safely when the app loses focus or its window closes.
- The editor appears as a normal Dock application while its editor or About window is open, supports Dock reopening and restoring minimized windows, and returns to menu-bar-only operation after the last window closes.
- Native Liquid Glass pads keep their colors visible when the editor is unfocused. Window-activation clicks work without replacing the native glass rendering.
- Shared mappings work across Launchpad Mini MK3, X, Pro MK3, and the virtual deck, with protected model-specific overrides and support for simultaneous devices.
- Reactive LED lighting, press effects, page animations, running-app status colors, LED artwork, and optional audio-reactive lighting. Microphone capture requires explicit opt-in.
- Extensions, community starter content, and a paired phone/tablet browser companion extend the available controls and actions.
- A more compact, adaptive editor improves deck sizing, application discovery, artwork loading, and configuration responsiveness.

## Fixes and distribution

- Fixed Swift concurrency errors in shortcut capture and kept event-tap cleanup on the main actor.
- Avoided an older Swift compiler crash when building actor-isolated picker bindings.
- Restored Xcode project-format compatibility for CI and Intel builds.
- Made the audio-permission revocation test wait for the health-check result instead of assuming a fixed scheduling delay.
- Made lighting integration checks deterministic using the renderer clock instead of fixed sleeps.
- Prevented the companion's selected-port test from competing with automatic outbound connections during parallel tests.
- Run timing-sensitive test suites sequentially and allow a bounded wait for scheduled lighting frames; all tests remain enabled.
- CI now checks the companion client, packaging scripts, property lists, both CPU architectures, and universal release artifacts.
- Includes drag-to-install DMG and ZIP downloads with SHA-256 checksums. App version: 0.2.0 (build 3).

## Installation

Requires macOS 26 or later. Both Apple silicon and Intel Macs are included in the universal app.

This is an **ad-hoc signed, unnotarized preview**, matching the project's preview distribution workflow. macOS may require approval in Privacy & Security before opening. Keyboard actions require Accessibility access (called Device Control and Data Access on macOS 27); shortcut recording also requires Input Monitoring. Grant microphone access only if you enable audio-reactive lighting.

Existing profiles and assignments are preserved. Manual profile overrides now reset on restart rather than remaining pinned.
