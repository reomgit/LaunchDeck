# Native UI fixes — 2026-10-16

Ownership: `LaunchDeck/Views/LaunchpadSurface.swift` and titlebar Pause controls in `LaunchDeck/LaunchDeckApp.swift`. Existing dirty checkout preserved; no commit, reset or stash.

## Investigation and causes

- On the original native app, an accessibility button action selected the pad and changed the inspector, but an actual pointer click on the blank glass face did nothing. The plain Button label contained an empty VStack with a visual glass effect but no explicit interaction content shape. A rectangular `contentShape` now covers the padded label. No execution is added to clicks.
- The original selection overlay was inside the glass Button label. Selecting via accessibility showed the correct inspector without any visible ring. Moving the ring to the outer pad view above the glass renders it visibly; the ring is explicitly blue and cannot intercept input.
- The face used every binding's stored color, including `.disabled`. The face and foreground now treat disabled bindings like neutral unassigned controls; the disabled label/action metadata remain visible.
- Pause already directly bound `isPaused`, which initialized false. The old label was hidden, making its purpose ambiguous. It now visibly says Pause, with an accessory wide enough for it and explicit running/paused help. The direct binding is unchanged.
